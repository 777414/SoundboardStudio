# Soundboard Studio

Учебный проект на Python и CustomTkinter.

## Возможности проекта

- звуковая коллекция без встроенных звуков;
- четыре категории: Эффекты, Голоса, Сигналы, Разное;
- импорт WAV-файлов;
- запись звука с микрофона до 5 секунд;
- прослушивание записи перед сохранением;
- переименование и удаление пользовательских звуков;
- сохранение коллекции в JSON.

## Установка

В терминале в папке проекта выполните:

```bash
py -m pip install -r requirements.txt
```

## Запуск

```bash
py main.py
```

Классы приложения не используются. Интерфейс и логика организованы с помощью отдельных файлов и функций.
