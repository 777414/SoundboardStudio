# Soundboard Studio

Простая звуковая панель на Python и CustomTkinter.

## Возможности

- пустая коллекция при первом запуске;
- воспроизведение WAV нажатием кнопки;
- одновременно играет только один звук;
- кнопка остановки;
- запись с микрофона до 5 секунд;
- прослушивание записи перед сохранением;
- повторная запись;
- импорт WAV без предварительного прослушивания;
- переименование и удаление звуков;
- новые звуки отображаются первыми;
- сохранение коллекции в JSON.

## Установка

В терминале в папке проекта выполни:

```bash
py -m pip install -r requirements.txt
```

## Запуск

```bash
py main.py
```

Приложение рассчитано на Windows 10/11. Код написан на функциях, без собственных классов.
